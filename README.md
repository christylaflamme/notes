# notes

Christy LaFlamme's personal notes, cheat sheets, and reusable code snippets, collected in one place.

| Folder | What's in it | Formerly |
|---|---|---|
| [`cheatsheet/`](cheatsheet/) | Everyday commands: VS Code, tmux, Slurm, conda/mamba, IGV, Git, Pixi, Kopah, plus `get-node.py` and an `sbatch` template | `CommonlyUsedCodeCheatSheet` |
| [`errors/`](errors/) | Errors I've hit and how I fixed them (R/RStudio on HPC, Ubuntu, IGV) | `errorHandling` |
| [`bash/`](bash/) | Handy Linux commands and small bash/awk scripts | `niftyLinuxCommands`, `niftyScripts` |
| [`R/wrangling/`](R/wrangling/) | R data-wrangling patterns I use a lot | `R_data_wrangling` |
| [`R/functions/`](R/functions/) | Reusable R analysis functions (DNA methylation, epigenetic clocks, snRNA nomenclature, ...) | `niftyRFunctions` |

The original repos are archived and read-only, and each one links here. Their full commit history was carried over into these folders.
