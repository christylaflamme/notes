# Zhou Lab epigenetic clock models

The `.rds` clock models used by [`getEpigeneticAges.R`](../getEpigeneticAges.R), from Zhou Lab's [InfiniumAnnotationV1](https://github.com/zhou-lab/InfiniumAnnotationV1). See the [SeSAMe epigenetic clock docs](https://zhou-lab.github.io/sesame/v1.18/inferences.html#Age__Epigenetic_Clock).

`EPICv1_to_EPICv2_probeID_nomenclature.txt` (25 MB) was left out of this repo to keep it light. It's still in the archived [niftyRFunctions](https://github.com/christylaflamme/niftyRFunctions/tree/main/zhou-lab_epigenetic_age_models) repo.
