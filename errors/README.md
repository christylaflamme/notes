# Using R/Rstudio on the HPC

## Installing packages


  Method 1: 
    Install packages using an interactive R studio image
    Set R_LIBS_USER in bashrc 
    
 ```bash
export R_LIBS_USER=/path/to/library
```
 
 
 
  Method 2:
    Install packages using terminal interactive R
    Set R_LIBS_USER in bashrc
